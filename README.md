## 带宽和流量：一个管速度，一个管总量

算账的第一步是把这两个词分开。带宽的单位是 Mbps（兆比特每秒），代表传输速度的上限；流量的单位是 GB 或 MB，代表实际传了多少数据。两者隔着 8 倍换算：1 字节（Byte）= 8 比特（bit），所以 1Mbps 带宽的下载速度上限约 128KB/s，10Mbps 约 1.25MB/s，200Mbps 的理论峰值也只有 25MB/s 左右。

很多宣传页写「200M 带宽」，读者理解成「每月 200M 流量」，这是最常见的误会。带宽像马路的车道数，决定同时能跑多快；流量像这个月累计运走的货量。马路再宽，不代表每月一定运那么多货。

顺手算一个有用的数：1Mbps 带宽满速跑一整天，大约能传出 10.5GB，一个月的理论上限也就 300GB 出头。反过来看，如果你的网站每月出向流量只有几个 GB，买大带宽基本是在为闲置的速度付费。

## 两种计费方式，账单算法完全不同

固定带宽是「先付钱买速度」：按月或按年买断 1M、3M、5M 这样的带宽值，周期内速度上限固定，流量随便跑，不再额外扣钱，账单等于服务器基础费用加带宽费。按流量是「先跑后付」：带宽峰值通常给得比较高，实际用掉多少出向 GB 就按单价扣多少，一般按小时结算、每日出账。

## 只有出方向收费：上传和内网流量是免费的

这一条能实实在在省钱，但不少入门文章没讲细。以阿里云的规则为例：只有公网出方向流量计费，用户从服务器下载数据才产生费用；你从本地上传文件到服务器，入方向免费；同一内网里服务器之间互传，也免费。Google Cloud 的规则类似，入站流量不收费，但对「内部流量」拆得更细：同一可用区内用内网地址互传免费，同一区域跨可用区收 0.01 美元/GiB，跨区域按距离收 0.02–0.14 美元/GiB。

这对实际部署的含义很直接：把数据库、缓存和应用服务器放在同一内网、同一可用区，它们之间通信不花钱或只花很少的钱；真正计费的出向流量，只发生在服务器把页面和数据发给访客那一段。反过来，应用和数据库如果分散在不同地域，跨区域流量费会悄悄变大。

## 四个让流量账单失控的坑

**第一，攻击和爬虫跑的是你自己的流量。** DDoS 攻击产生的出网流量，多数厂商默认计入按量计费，一夜刷出几百上千元账单的情况真实存在。对策是开流量告警、设流量封顶，公开服务优先考虑固定带宽或高防。

**第二，「200M 带宽 38 元一年」式的低价，通常叠了四重限制：** 限新用户、限入门规格、给的是按流量计费的峰值带宽加一个月流量包、续费恢复原价。看到这类活动，先把页面上的适用规格、续费价格、是否限制流量找出来再下单，很多误会到这一步就排除了。

**第三，固定带宽买的是持续上限。** 短时间瞬时冲高会被限速，高峰期页面变慢。带宽值别卡着日常峰值买，留一点余量。

**第四，流量之外的杂项也会慢慢长大。** 快照按占用的存储空间收费，自定义镜像按存储收费，CDN 流量和服务器公网流量是两本分开的账。长期保留一堆旧快照，账单里就会多出一笔看起来莫名其妙的存储费。

## 几个高频疑问

**上传文件到服务器收流量费吗？**
不收。收费的只有出方向——服务器把数据发给用户。往服务器上传、服务器之间内网互传都免费（Google Cloud 跨可用区互传除外，收 0.01 美元/GiB）。

**1Mbps 带宽够用吗？**
看业务。静态博客、低频调用的 API 足够——满速 128KB/s，一天的流量上限约 10.5GB。带图片的列表页、几十人同时在线就紧张了，固定带宽建议按峰值留余量。

**内网流量收费吗？**
主流厂商内网免费，阿里云的内网流量完全不收费。跨地域、跨厂商的传输另算，比如 Google Cloud 跨区域收 0.02–0.14 美元/GiB。

**被攻击产生的流量费要自己承担吗？**
按量计费模式下，多数厂商默认把攻击产生的出网流量计入账单，需要用户承担。所以公开站点要么上固定带宽，要么至少把流量告警和封顶打开。
